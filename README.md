复利计算器是一款功能强大且易用的 iOS 应用程序，专为投资理财规划而设计。支持多种投资场景计算，包括一次性投资、定期投资和目标导向计算。采用高精度 Decimal 计算引擎，确保金融计算的准确性。

## 计算公式

### 复利公式
```
A = P(1 + r/n)^(nt)
```
- A: 最终金额
- P: 本金
- r: 年利率
- n: 每年复利次数
- t: 时间（年）

### 定期投资公式
```
A = P(1 + r/n)^(nt) + PMT × [((1 + r/n)^(nt) - 1) / (r/n)]
```
- PMT: 定期投资额
